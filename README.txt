CAREERPATH — STANDALONE WEBSITE
================================

This edition is designed to run without Python, Flask, a database server, API keys,
or package installation. It is a static website using HTML, CSS and JavaScript.

HOW TO OPEN
-----------
1. Extract the ZIP file.
2. Open the extracted CareerPath-Standalone folder.
3. Double-click index.html.
4. The website opens in your browser.
5. Create an account from the Create account tab, then sign in.

FEATURES INCLUDED
-----------------
- Sign up, sign in and local demo password reset
- Student dashboard
- Career explorer
- Courses and learning resources
- Scholarship information links
- Jobs and internship portals
- Career roadmap
- Aptitude practice quiz with score
- Career guidance assistant (rule-based demo)
- Resume builder with print / Save as PDF
- Personal bookmarks
- Responsive layout for laptop and mobile

IMPORTANT LIMITATIONS
---------------------
This is a front-end demonstration. Account details and passwords are stored in the
browser's localStorage, so this is NOT secure production authentication and must not
be used for real sensitive accounts or deployed as a public login system.
The career assistant is rule-based, not connected to an AI model.
Scholarship and job entries are starting links, not guaranteed active listings.
Always verify eligibility, deadlines and job details on official websites.
Use the same browser profile to retain the demo account and bookmarks.

TROUBLESHOOTING
---------------
- If styles do not load, keep the assets folder beside index.html.
- If you previously opened another CareerPath copy, make sure you open this
  extracted folder's index.html.
- No terminal commands or Python installation are required.
